    ⚙️ Настройка

    Один раз: бот и секреты GitHub.

    Бот

    Токен хранится только в этом браузере, зашифрованный вашим входом в пульт, и на GitHub не попадает. Где взять: в Telegram откройте @BotFather → /newbot → скопируйте токен. Затем в канале: Управление → Администраторы → добавить бота.

    Без VPN: если Telegram не открывается (в России так бывает) или токен здесь не сохранён, пульт отправит через робота GitHub — до минуты, в чаты из секрета TG_CHAT (см. «Сам, без пульта» ниже).

    🔐 Настройки бота

    Токен, канал, секретное слово и доступ к Cloudflare. Сохраняются зашифрованными прямо в секреты GitHub — видеть их потом не сможет никто, даже пульт: только заменить. Пустое поле — не менять.

    «Применить» — робот сам загрузит код бота в Cloudflare, пропишет токен и слово, подключит конкурсы и адрес для Telegram. Нажимайте после смены токена или обновления пульта. Нужен API-токен с шаблоном «Edit Cloudflare Workers» (в нём есть и хранилище KV); для перевода добавьте в токен право «Workers AI».

    💬 Бот отвечает сам (Cloudflare)

    Бот в личке отвечает на частые вопросы и принимает нажатия «Участвую» в конкурсах. Работает на бесплатном Cloudflare Workers — круглосуточно. Проще всего: зарегистрируйтесь на dash.cloudflare.com, впишите Account ID и API-токен в «🔐 Настройки бота» выше и нажмите «Применить». Ниже — то же самое вручную.

    Настроить вручную
    1. Зарегистрируйтесь на dash.cloudflare.com (бесплатно) → Workers & Pages → Create → Worker → имя apex-bot → Deploy.
    2. Edit code → удалите всё и вставьте код бота: → Deploy.
    3. Settings → Variables and Secrets → Add, тип Secret:
      • BOT_TOKEN — токен бота от @BotFather;
      • WEBHOOK_SECRET — секретное слово. Нажмите и вставьте его:
      • по желанию OWNER_ID — ваш номер в Telegram (узнать у @userinfobot): команды /draw и /contests.
    4. Для конкурсов: Storage → KV → Create namespace apex-bot; затем в Worker → Settings → Bindings → KV namespace, имя APEX_KV.
    5. Откройте в браузере https://apex-bot.<ваше-имя>.workers.dev/setup?key=СЛОВО — увидите «Готово! Бот отвечает».
    6. Для итогов конкурсов по расписанию — секреты GitHub (как TG_BOT_TOKEN): BOT_WORKER_URL = адрес Worker (https://…workers.dev) и BOT_WORKER_KEY = то же слово.

    Токен бота хранится только в секретах GitHub и Cloudflare. Робот GitHub продолжает публиковать посты как раньше.

    📝 Тексты бота

    Что бот отвечает в личке: приветствие, темы-кнопки, слова для поиска и ответы. Бот подхватит изменения за 5 минут — код в Cloudflare менять не нужно. Если вы ставили бота до этой версии пульта, один раз обновите код: «Скопировать код бота» → вставить в Cloudflare → Deploy. В текстах можно писать {сайт} и {поддержка} — подставятся ссылки.

    🤖 Сам, без пульта

    Робот GitHub сам пишет в канал: о новой версии (номер и список изменений) и о техработах — когда вы ставите пометку «Обслуживание» на сервер, когда меняете время и когда работы закончились. Срабатывает сразу после «Сохранить» и сам «просыпается» к концу техработ.

    1. GitHub → репозиторий apex-client → Settings → Secrets and variables → Actions → New repository secret.
    2. Имя TG_BOT_TOKEN — токен бота. Ещё один: TG_CHAT — @имя_канала, группа — @имя_группы или номер -100…; оба — через запятую.
    3. Готово. Первый раз робот только запомнит, что сейчас есть, и ничего не отправит — дальше будет писать о новом.

    Проверка

    Проверяется из вашего браузера и вашей сети. Если у вас включён VPN, результат может отличаться от того, что видят пользователи без него.

    Перед выпуском и после него: сборки зелёные, всё сохранено, версия везде одна, справка, видео «Что нового» и канал в порядке.

    Ссылки в пульте

    Все ссылки из баннеров, объявления, «Ссылок» и визитки: правильно ли написаны и открываются ли. Из браузера видно только «сайт отвечает или нет» — страницу «не найдено» на живом сайте так не поймать.

    Серверы

    Грубая проверка из браузера: отвечает ли адрес и за сколько. Список хранится только в этом браузере и никуда не отправляется — адреса серверов не попадают на GitHub. Строка: Название = адрес:порт.

    «Отвечает» значит, что сервер принял соединение. Проверить сам VPN так нельзя — для этого есть пинг в приложении. Если у вас включён VPN, результат может отличаться.

    🎛 Как работает пульт

    Пульт меняет файл docs/config/app.json на GitHub. Приложения забирают его при запуске, при открытии (не чаще раза в 5 минут) и раз в 15 минут в фоне — изменения доходят за 1–15 минут. Новую версию приложения выпускать не нужно.

    Вход: первый раз — токен GitHub и PIN из 4–8 цифр, дальше только PIN. Токен хранится только в этом браузере, зашифрованный PIN-ом.

    НазваниеВ шапке — APEX CLIENT, версия пульта и приложения. Иконка «щит с ползунками» — на вкладке браузера и на главном экране телефона (Chrome → ⋮ → «Добавить на главный экран»)
    Меню и поискВкладки разложены по группам (на телефоне — нижнее меню). ✏️ возле поиска — свой порядок вкладок (перетаскиванием за ⠿ или ↑↓) и скрытие редких. Поиск (Ctrl+K) находит вкладку, поле и содержимое: тексты баннеров, серверы, объявление, обои. Ctrl+S — сохранить, клавиши 1–9 — вкладки, ? — список клавиш
    ОбзорЧто видят пользователи, версии, календарь на 2 недели (баннеры, техработы, объявление), быстрые действия (убрать все баннеры, снять пометки, удалить закончившееся, вернуть как до последнего сохранения), «Неделя», скачивания по версиям и по дням, 📺 большой экран (клавиша B), 🔔 уведомления о красной сборке, аварийный режим
    БаннерыПолоса на главном экране: название для себя, расписание «с … до …», устройства, страна оператора, версии, шаблоны. Порядок важен — приложение показывает первый подходящий, двигайте за ⠿. «🎉 Праздник: баннер + визитка» — праздник одной кнопкой. «⏳ Баннер «обновитесь»» — только для старых версий. Отметьте «Сайт» — баннер появится и на визитке

Быстрые кнопки: на 1, 2, 4 часа или до 9:00. Можно запланировать «с … до …» — кто выбрал сервер вручную, получит уведомление за ~15 минут (с 3.19) Порядок пометок — за ⠿
    ОбъявлениеБольшое окно с картинкой и кнопкой, показывается один раз, можно по расписанию. Шаблоны: новая версия, техработы, праздник, канал. «Показать снова всем» — увидят ещё раз
    СсылкиПоддержка, канал, сайт — в приложении: Настройки → О приложении. Сайт показывается с 3.19.5

    ФункцииЭкстренно выключить LTE-автопереход, HaGeZi, защиту от мошенников, автоустановку обновлений

    ОбоиКаталог живых обоев в приложении: добавить по ссылке на .mp4, порядок (за ⠿), разделы, скрыть, убрать. Источники поиска (Pixabay, Pexels, Wikimedia, GIPHY) — включить, ключи, порядок. Темы поиска (аниме, игры, неон…) — свои названия и слова. «Обои дня» — раз в день новые обои сами

    ПроверкаОткрываются ли подписка и поддержка, дошёл ли файл до GitHub и зеркала. «Проверить ссылки» — все ссылки баннеров, объявления, «Ссылок» и визитки. «Серверы» — грубая проверка адресов, список только в этом браузере

    📶 Подписка, Xray JSON и LTE-обход
    • Понимает base64-список, обычный список, JSON sing-box и Xray JSON. User-Agent: APEX VPN/версия.
    • LTE-обход узнаётся по названию: LTE, 📶, Обход, Bypass, Белые списки.
    • Если у обхода особые настройки (XHTTP, CDN) — Response Rules → «User-Agent содержит APEX VPN» → тип ответа XRAY_JSON.
    • Сменили домен подписки — вкладка «Подписка»: новый адрес первым + строка переезда «старый = новый».
    🩺 GitHub не собирает или сайт не открывается
    • Actions: жёлтый — в очереди, зелёный — готово, красный — ошибка.
    • Долго в очереди или «startup_failure» — обычно сбой у GitHub. Подождите и нажмите Re-run jobs.
    • Лимиты не тратятся: репозитории публичные, Actions бесплатные. Старые файлы сборок удаляет ежедневная очистка.
    • Сайт показывает 404 — проверьте, прошёл ли pages-build-deployment, и Settings → Pages.
    • Красный ✗ у коммита бывает, когда лишнюю сборку отменили вручную — это не ошибка, следующая версия будет зелёной.
    • Картинка в README не обновилась — Ctrl+F5 или подождите 5–10 минут: GitHub держит картинки в кэше.
    • Красная полоса «Сборка упала» в пульте — см. раздел «Автопроверки» выше.

    Не подключается

    Откройте APEX CLIENT, нажмите ↻ «Обновить подписку» на главном экране и выберите «Автопилот». Если не помогло — выключите и включите VPN. Не заработает — пришлите скриншот главного экрана.

    Медленно работает

    Включите «Автопилот» — он сам выбирает самый быстрый сервер. На мобильном интернете попробуйте сервер с пометкой 📶 LTE или «Обход».

    Как обновить приложение

    Обновление приходит само: появится окно «Доступна версия» или плашка «Вышла версия … Обновить» вверху главного экрана — нажмите «Обновить». Можно проверить вручную: Настройки → Обновления → «Проверить сейчас». Версии до 3.19.3 обновите один раз вручную: скачайте файл apex-client-….apk с сайта dubstep2004.github.io.

    Как добавить подписку

    Скопируйте ссылку подписки, откройте APEX CLIENT и в поле «Ссылка на подписку» нажмите значок «Вставить». Или «Сканировать QR-код».

    Где скачать

    Сайт dubstep2004.github.io — кнопка «Скачать». Файл для телефона и ТВ — apex-client-….apk, для часов — apex-watch-….apk.

    Приложение называется по-другому

    APEX VPN теперь называется APEX CLIENT — это то же приложение, подписка и настройки на месте.

    Техработы на сервере

    На сервере сейчас техработы. Автопилот уже переключил вас на рабочий. Если выбирали сервер вручную — нажмите «На автопилот» в уведомлении.

    Есть несохранённые изменения

    APEX CLIENT · шпаргалка владельца

    Пульт: dubstep2004.github.io/apex-client/admin/ · Сайт: dubstep2004.github.io · Пульт 2.11

    Пульт

    • Изменения доходят до приложений за 1–15 минут
    • Не забудьте «Сохранить» (Ctrl+S), отменить — ↶ или Ctrl+Z
    • «История» — вернуть прошлую версию
    • VPN перезапускается только из-за серверов, функций и кода предпросмотра

    Если всё сломалось

    • «Обзор» → «Включить аварийный режим» → Сохранить
    • Сервер сбоит — «Серверы» → 🔧 Обслуживание на 1–4 часа
    • Плохая версия — «Функции» → выключить автоустановку, номер — в «Отозванные версии»

    Выпуск версии

    • build.gradle.kts: versionCode +1, versionName
    • Changelog.kt — запись
    • Push в main → сборка ~25 минут → релиз
    • Бета — в имени слово beta

    Токен (403)

    • github.com/settings/personal-access-tokens/new
    • Only select repositories → apex-client
    • Contents → Read and write, 90 дней
    • Токен никому не присылать

    Автопроверки

    • 🟢 всё хорошо · 🟡 идёт · 🔴 ошибка · ⚪ отменена
    • Красная полоса в пульте → открыть проверку → Annotations

    Нельзя менять

    • Метку APEX VPN/версия в Remnawave
    • Пакет com.apexvpn.client и ключ подписи
    • Не создавать репозиторий apex-vpn

    🎉 Праздник одной кнопкой

    Пульт добавит праздничный баннер в приложение (сам исчезнет после праздника) и включит оформление на визитке.

    Сохранить позже

    Изменения сохранятся сами в выбранное время (робот GitHub «просыпается» к этому времени, обычно в течение 1–2 минут). Пульт можно закрыть.
