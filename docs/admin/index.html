Пульт APEX VPN

Баннер, серверы, ссылки и обновления для всех пользователей — без новой версии приложения.

Токен хранится только в этом браузере и никуда не отправляется, кроме GitHub.

Где взять токен
  1. Откройте создание токена на GitHub.
  2. Срок — 90 дней. Repository access → Only select repositories → apex-vpn.
  3. Permissions → Contents: Read and write. Остальное не трогайте.
  4. Generate token, скопируйте и вставьте сюда.
