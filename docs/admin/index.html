🎛 Как работает пульт

Пульт меняет файл docs/config/app.json на GitHub. Приложения забирают его при запуске, при открытии (не чаще раза в 5 минут) и раз в 15 минут в фоне — изменения доходят за 1–15 минут. Новую версию приложения выпускать не нужно.

Вход: первый раз — токен GitHub и PIN из 4–8 цифр, дальше только PIN. Токен хранится только в этом браузере, зашифрованный PIN-ом.

🔑 Новый токен (срок вышел или ошибка 403)
  1. Откройте github.com/settings/personal-access-tokens/new
  2. Token name: APEX admin, Expiration: 90 дней.
  3. Repository access → Only select repositories → Dubstep2004/apex-vpn. «Public repositories» (по умолчанию) — только чтение, будет 403.
  4. Permissions → «+ Add permissions» → Contents → Read and write.
  5. Generate token → скопируйте → здесь «Выйти и стереть токен» → войдите с новым.
Токен — как пароль. Никому не присылайте, в том числе в чаты и боту.
👁 Код предпросмотра
  1. Вкладка «Предпросмотр» → код или «Придумать» → Сохранить.
  2. Приложение → Настройки → О приложении → «Код предпросмотра» → тот же код. Приложение напишет «Код подошёл» или «Код не совпадает».
  3. У баннера, объявления или пометки включите «Только предпросмотр» → Сохранить. Видите только вы.
  4. Проверили — снимите галочку и сохраните: увидят все.
Каждое «Придумать» делает новый код — старый на телефоне перестаёт работать.

🛠 Выпуск новой версии и беты
  1. app/build.gradle.kts — увеличьте versionCode и versionName.
  2. Changelog.kt — добавьте запись: это описание релиза и окна обновления.
  3. Запушьте в main (или Actions → Build APEX VPN → Run workflow). Сборка ~25 минут, потом релиз и окно «Доступна версия».

Бета: имя со словом beta (3.19.0-beta1) — выйдет как Pre-release, получат только с «Настройки → Обновления → Бета-версии».

Плохая версия: «Функции» → выключить автоустановку обновлений, номер сборки — в «Отозванные версии».

Все версии подписываются одним ключом (секреты APEX_KEYSTORE_BASE64 / APEX_KEYSTORE_PASSWORD). Не удаляйте их и храните копию ключа — иначе обновления не встанут поверх.
📢 Объявление в карточке подписки (Remnawave)
  1. Remnawave → Подписка → поле объявления (announce), до 200 символов → Сохранить.
  2. Картинка и кнопка: допишите ![](https://сайт/b.jpg) и [Продлить](https://сайт/pay).
  3. Убрать — очистите поле или впишите 0.

Не приходит — добавьте правило ответа с additionalExtendedClientsRegex: ["^APEX VPN/"]: APEX получит то же, что Happ (объявление, описания серверов, support-url).

📶 Подписка, Xray JSON и LTE-обход
  • Понимает base64-список, обычный список, JSON sing-box и Xray JSON. User-Agent: APEX VPN/версия.
  • LTE-обход узнаётся по названию: LTE, 📶, Обход, Bypass, Белые списки.
  • Если у обхода особые настройки (XHTTP, CDN) — Response Rules → «User-Agent содержит APEX VPN» → тип ответа XRAY_JSON.
  • Сменили домен подписки — вкладка «Подписка»: новый адрес первым + строка переезда «старый = новый».
🩺 GitHub не собирает или сайт не открывается
  • Actions: жёлтый — в очереди, зелёный — готово, красный — ошибка.
  • Долго в очереди или «startup_failure» — обычно сбой у GitHub. Подождите и нажмите Re-run jobs.
  • Лимиты не тратятся: репозитории публичные, Actions бесплатные. Старые файлы сборок удаляет ежедневная очистка.
  • Сайт показывает 404 — проверьте, прошёл ли pages-build-deployment, и Settings → Pages.
