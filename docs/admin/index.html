APEX VPN · админка

Изменения сохраняются в репозиторий Dubstep2004/apex-vpn, приложения подхватывают их в течение часа — без новой версии.

Вход

Токен хранится только в этом браузере. Никому его не присылайте.

Как получить токен
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → apex-vpn.
  3. Permissions → Repository permissions → Contents: Read and write. Остальное не трогать.
  4. Срок (Expiration) — например, 90 дней. Generate token → скопировать сюда.

📢 Баннер на главном экране

Пользователь может закрыть баннер — новый текст покажется снова.

🖥 Серверы

Сервер ищется по части названия без флага: «Германия» — все немецкие, «Обход №1» — один сервер.

«Обслуживание» и скрытые серверы автопилот не выбирает (если остаётся хоть один другой).
